# Karabiner Config

Personal Karabiner-Elements settings and custom rules.

## Complex Modifications

### Right Command input source

The [custom rule](complex-modifications/right-command-input-source.json)
sends `fn` when Right Command is tapped alone within 250 ms. Holding
Right Command does not act as Command.

Configure macOS to change input source when the Fn/Globe key is pressed
for the tap to switch input sources.

To add the rule:

1. Open Karabiner-Elements and go to **Complex Modifications**.
2. Choose **Add your own rule**.
3. Paste the JSON from the linked file into the editor and save it.
