# Karabiner Config

Personal Karabiner-Elements settings and custom rules.

## Right Command input source

The [custom rule](complex-modifications/right-command-input-source.json) sends `fn` when Right Command is tapped alone within 250 ms. Holding Right Command does not act as Command. Configure macOS to change input source when the Fn/Globe key is pressed for the tap to switch input sources.

To add the rule, open Karabiner-Elements, go to **Complex Modifications**, choose **Add your own rule**, and paste the JSON from the file into the editor. Save the rule.
